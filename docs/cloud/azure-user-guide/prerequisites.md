!!! info "Before you begin"

    Before you install and run Jaspersoft Business Intelligence on Azure, ensure that you meet the following requirements:

-   Azure account. If you already have an account, [log in to Azure](https://portal.azure.com/). To create an Azure account, go to the [Azure portal](https://portal.azure.com/), click the Create Account, and follow the instructions.

-   Default database credentials used for JasperReports Server. To get the credentials, Secure Shell(SSH) credentials into the JasperReports Server instance and look in the ./buildomatic/default_master.properties file.

    !!! note

        The dbPassword changes from instance to instance but is similar to `dbUsername=jasperserverdbPassword=19d0963c24f89e80d6beb600edbcc3905f8079627551af8a74611bf960755edfIf`.
