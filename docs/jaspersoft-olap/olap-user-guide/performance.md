# Performance

Jaspersoft offers a number of tools to help you improve the performance of views and reports based on OLAP data:

- Many of the options on the OLAP Settings page can improve performance. See [Changing OLAP Settings](changing_olap_settings.md).

- Caching can significantly improve performance, especially when you can configure it to handle your particular data load gracefully. Caching is discussed in:

  - [Changing OLAP Settings](changing_olap_settings.md)

  - [Flushing the OLAP Cache](flushing_the_olap_cache.md)

  - [Configuring the XML/A Cache](configuring_the_xml_a_cache.md).

- To help you understand bottlenecks and other performance problems, Jaspersoft offers a number of OLAP views and report that capture information about how the OLAP engine is performing against your views and reports. See [Performance Tuning](performance_tuning.md) and the Jaspersoft OLAP Ultimate Guide.
