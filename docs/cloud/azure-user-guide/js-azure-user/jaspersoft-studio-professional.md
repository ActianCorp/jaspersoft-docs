# Working with Jaspersoft Studio Professional

You can create sophisticated, pixel-perfect reports on the desktop and upload those reports to JasperReports Server on Azure using Jaspersoft Studio. You can also create sophisticated layouts containing charts, images, subreports, crosstabs, and more.

## Downloading Jaspersoft Studio

Jaspersoft Studio is available as an Eclipse Rich Client Package (RCP), you can download it from [Jaspersoft Community](http://community.jaspersoft.com/project/jaspersoft-studio/releases) website.

For more information about installing Jaspersoft Studio and your license on your local machine, see the TIBCO Jaspersoft® Studio User Guide.
