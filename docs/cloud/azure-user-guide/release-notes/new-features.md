# New Features

This is the first release of TIBCO JasperReports® Server for Microsoft Azure. This release provides a web-based alternative to the Jaspersoft Studio with a new visual designer.

The following features are included in this release:

Cloud Repositories

TIBCO JasperReports® Server for Microsoft Azure provides options to connect to cloud repositories, including Google, GitHub, and JasperReports Server. You can create, read, update, and delete the resources stored in these repositories. TIBCO JasperReports® Server for Microsoft Azure also supports creating and editing JRXML files in repositories.

JRXML Editor

JRXML Editor feature is supported in TIBCO JasperReports® Server for Microsoft Azure. You can drag and drop elements from the palette, move and resize them.

Properties Editor

You can use Properties Editor to set all properties of an element. The following features of Properties Editor are not supported for this release:

- complex and custom properties editors
- properties description and validation
