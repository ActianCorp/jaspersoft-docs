# Authenticating to JasperReports Server

If you are implementing client-side authentication, Jaspersoft Studio provides a mechanism for importing a client certificate into a keystore.

!!! note

    Please note that this functionality is only supported by the Jaspersoft Community ([community.jaspersoft.com)](http://community.jaspersoft.com/). TIBCO Jaspersoft Technical Support and Engineering do not support it.
