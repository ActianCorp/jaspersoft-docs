# 1.1 Configuring Report Scheduling

Scheduled reporting allows you to run reports at specified times. And you have the option to send an email notification to users when a new report is available.

For more information about setting up report scheduling, refer to [Configuring Report Scheduling](../../../installation-guide/additional/configuring_report_scheduling.md).
