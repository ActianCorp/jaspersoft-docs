# Logging into the Server

1.  To log in, go to this URL:

`http://<hostname>:7001/jasperserver-pro`

Where `<hostname>` can be localhost, a machine name, or an IP address. The login page appears when the necessary JSP files are compiled.

1.  Enter the following credentials:

| User ID       | Password      | Description                                |
|---------------|---------------|--------------------------------------------|
| `superuser`   | `superuser`   | System-wide administrator                  |
| `jasperadmin` | `jasperadmin` | Administrator for the default organization |

!!! note

    The first time you log in, you are prompted to opt in to the JasperReports Server Heartbeat. For more information, refer to [JasperReports Server Heartbeat](../warfileinstall/war_logging_into_jrs.md).

Refer to the JasperReports Server User Guide to begin creating reports and other resources.
