## How to Contact Jaspersoft Support

You can contact Jaspersoft Support in the following ways:

- For an overview of Jaspersoft Support, visit <https://www.tibco.com/services/support>.
- For accessing the Support Knowledge Base, viewing the latest product updates that were not available at the time of the release, and getting personalized content about products you are interested in, visit the JaspersoftSupport portal at [https://support.tibco.com](https://support.tibco.com/).
- For creating a Support case, you must have a valid maintenance or support contract with Jaspersoft. You also need a user name and password to log in to [https://support.tibco.com](https://support.tibco.com/). If you do not have a user name, you can request one by clicking **Register** on the website.

Jaspersoft Community offers access to Q&A forums, product wikis, and best practices.

To join Jaspersoft Community, go to:

[https://community.jaspersoft.com](https://community.jaspersoft.com/)
