# Installation and Configuration

This document covers Jaspersoft for AWS Hourly and Annual Offerings as well as Jaspersoft for AWS BYOL (Bring Your Own License) and Jaspersoft for AWS with Multi-Tenancy. You can purchase the hourly and annual products directly on the AWS Marketplace. To purchase annual subscription licenses for BYOL contact Jaspersoft Sales.

This chapter assumes you have the basic knowledge of JasperReports Server. You can find Jaspersoft’s documentation on the Jaspersoft Community Site: <http://community.jaspersoft.com/documentation>.
