# Accessing the Source Code

To get access to the source code, contact the [Support team](https://www.jaspersoft.com/support).

All the information required to configure a development environment on the Eclipse IDE, compile and run the source code is provided in the [Jaspersoft Studio Source Build Guide](https://community.jaspersoft.com/documentation/jaspersoft%C2%AE-studio/tibco-jaspersoft%C2%AE-studio-source-build-guide/v900/jss-source-_-svn-source/).
