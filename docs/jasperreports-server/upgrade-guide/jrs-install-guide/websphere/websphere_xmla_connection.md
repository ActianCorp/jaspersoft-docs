# 1.1 Updating XML/A Connection Definitions (Optional)

If you loaded the sample data, and you want to run the Analysis XML/A examples, you'll need to update the XML/A connection resources to use the correct web port.

The typical port used by WebSphere is 9080. Follow the procedure in [Updating XML/A Connection Definitions](../../../installation-guide/additional/updating_xml_a_connection_definition.md).
