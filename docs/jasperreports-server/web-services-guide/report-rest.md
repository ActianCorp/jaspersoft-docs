# REST v1 - Report Services

For authentication using the REST web services, see section [REST Authentication](rest_authentication.md).

The RESTful report services gives responses that contain the same XML data structure that are used in the SOAP repository web service. These data structures are documented in section [Syntax of resourceDescriptor](syntax_of_resourcedescriptor.md), with reference material in [ResourceDescriptor API Constants](api-constants.md).
