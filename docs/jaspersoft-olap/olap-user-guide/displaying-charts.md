# Displaying Charts

Charts can provide more dramatic visual impact. Create a simple view to display as a chart.

To view a chart:

1\. From the Repository, open the Foodmart Sample Analysis View.

2\. Click ![ja pro change data cube](assets/images/ja-pro-change-data-cube.png).

3\. Click the **Move to Rows** icon next to the Store filter to create a row, then click **Store**.

4\. Expand All Stores in then USA, and select **CA**, **OR**, and **WA**. Click **OK**.

5\. Click the filter icon ![ja table filter](assets/images/ja-table-filter.png)next to **Promotion Media** and **Production** in the Rows section to remove them from the row.

6\. Click **OK**.

7\. Click **Collapse All** ![ja toolbar collapsepositionbutton](assets/images/ja-toolbar-collapsepositionbutton.png).

8\. Click **Show Chart** ![ja pro show chart](assets/images/ja-pro-show-chart.png).

A default chart output appears.
