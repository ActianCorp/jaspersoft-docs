# Localizing Controls

You can design dashboard controls to accommodate different languages. First, use the \$R syntax to define prompts and static lists of values. Next, attach resource bundles to the report that contain translations of the prompts and lists of values. Finally, add the report to the dashboard. For more information about how to localize input controls, see [Localizing Reports](../repo-upload-reports/repo-localizing-reports.md).
