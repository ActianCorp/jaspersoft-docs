# JasperReports® Server Telemetry Data Collection Program

The JasperReports Server Telemetry Program is designed to collect technical data about how JasperReports Server operates in your environment and how it's being used. This helps us understand product performance, common deployment environments, and usage patterns, ultimately leading to a better product and ensuring license compliance.

With this change, Actian is aligning the reporting of license telemetry data for on-premises products with the standard reporting provided in cloud services where the data is automatically collected and enforced as a part of service delivery.

For customers who cannot report licenses automatically due to being in isolated network environments, a process is available for the customer to manually collect and upload the license telemetry data upon renewal.

|  |  |  |
|----|----|----|
| Data Collected | Description | What we use it for |
| Product Usage | Application-level usage metrics, such as counts of logged-in users, the number of reports run, scheduled jobs, and various product configuration settings like Ad Hoc view creations, and information about the connected database type. | Optimize product performance across various deployment environments, identify hardware-related issues, and understand aggregated usage patterns. |
| License Usage | This refers to License Information (for example, License ID and Installation UUID) as well as technical system details (for example, Core counts, OS information). | We use this data to monitor license compliance. |
