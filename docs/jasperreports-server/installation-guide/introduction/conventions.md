# Conventions

This document uses the following conventions when referring to file locations:

<table>
<colgroup>
<col style="width: 50%" />
<col style="width: 50%" />
</colgroup>
<thead>
<tr>
<th><p>Convention</p></th>
<th><p>Description</p></th>
</tr>
</thead>

<tr>
<td><p>&lt;js-install&gt;</p></td>
<td><p>For binary installations, the directory where JasperReports Server will be installed by the binary installer. This directory contains directories for applications used by the installer, such as apache-tomcat and postgresql, as well as directories for JasperReports Server, such as samples.</p>
<p>For manual installations, the directory where you unpack the WAR file distribution <span></span></p>
<p><code>js-jrs</code><code>_10.1.0</code></p>
_bin.zip.</td>
</tr>
<tr>
<td><p>&lt;java&gt;</p></td>
<td><p>The directory where Java is installed.</p></td>
</tr>
<tr>
<td><p>&lt;jboss&gt;</p></td>
<td><p>The directory where JBoss is installed.</p></td>
</tr>
<tr>
<td><p>&lt;postgresql&gt;</p></td>
<td><p>The directory where PostgreSQL is installed. If you use our bundled instance of PostgreSQL, it is in the &lt;js-install&gt; directory.</p></td>
</tr>
<tr>
<td><p>&lt;tomcat&gt;</p></td>
<td><p>The directory where Apache Tomcat is installed. If you use our bundled instance of Tomcat, it is in the &lt;js-install&gt; directory.</p></td>
</tr>
