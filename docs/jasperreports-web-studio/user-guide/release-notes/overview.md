# Overview

JasperReports® Web Studio Edition is the set of tools to run and edit report templates for the JasperReports® Library reporting engine. The whole Jaspersoft family of products that use this open source library to produce dynamic content and rich data visualizations.

It comes as a web-based alternative to Jaspersoft Studio, the desktop application, which is the most complete and powerful designer for JasperReports templates.
