# Report Bursting

Report bursting is the process of running a report once and distributing its data to different recipients relevant to them. For example, recipients in different countries need a report on shipping data for their country. The recipients can receive the burst report through email.

Bursting a report needs a list of recipients to whom you want to send the burst report and a bursting report containing a scriptlet attached to its dataset. This bursting report triggers the bursting operation.

When you run a bursting report from the repository, it triggers the burst operation. The burst report that you want to send to recipients is stored in the output folder in the repository. For more information on the report bursting, see the Jaspersoft Studio User Guide.

You can also schedule the burst report. For more information on scheduling a report, see [Scheduling a Report](reports-scheduling.md).
