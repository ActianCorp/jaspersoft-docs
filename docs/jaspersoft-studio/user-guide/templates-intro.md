# Report Templates

Templates are one of the most useful tools in Jaspersoft Studio. You can use the provided templates as the basis for new reports. You can also use a template as a model and add fields, text fields, and groups in the Report Wizard.

This chapter explains how to build custom templates that appear in the Template Chooser. It has the following sections:

- [Template Structure](templates-structure.md)

- [Creating and Customizing Templates](templates-creating.md)

- [Saving Templates](templates-saving.md)

- [Adding Templates to Jaspersoft Studio](templates-adding-as-template.md)

!!! note

    You can also create JasperReports Server templates and upload them to the server. See [1.1, “Working with Templates,” on page 1](jrs-server/jss2jrs-report-template.md).
