# 1.1 System Requirements

Before getting started with version 1.9 the Jaspersoft Mobile SDK for Android, take a moment to confirm that your development computer meets the following system requirements.

<table>
<colgroup>
<col style="width: 100%" />
</colgroup>
<thead>
<tr>
<th><p>Supported Operating Systems</p></th>
</tr>
</thead>
<tbody>
<tr>
<td><p>Windows 8, 7, Vista, or 2003 (all 32- or 64-bit)</p></td>
</tr>
<tr>
<td><p>Mac OS X 10.8.5 to 10.9 (x86 only)</p></td>
</tr>
<tr>
<td><p>Linux:</p>
<ul>
<li>Tested on Ubuntu Linux, Lucid Lynx</li>
<li>On Ubuntu Linux, version 8.04 or later is required</li>
<li>GNU C Library (glibc) 2.7 or later is required</li>
<li>64-bit distributions must be capable of running 32-bit apps (see the Ubuntu Linux installation notes)</li>
</ul></td>
</tr>
</tbody>
</table>

The Jaspersoft Mobile SDK for Android can be used with the following integrated development environments (IDEs):

| Supported IDEs |
|----|
| Android Studio 1.0 or later |
| Intellij IDEA 13 or later (see the [Intellij IDEA help](https://www.jetbrains.com/idea/help/android.html)) |
