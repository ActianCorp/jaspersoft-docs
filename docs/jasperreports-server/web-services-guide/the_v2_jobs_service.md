# 1.1 The v2/jobs Service

The rest_v2/jobs service provides the interface to schedule reports and manage scheduled reports (also called jobs). It replaces the functionality of the jobsummary and job services. In addition, the new service provides an API to scheduler features that were introduced in JasperReports Server 4.7, such as bulk updates, pausing jobs, FTP output and exclusion calendars.
