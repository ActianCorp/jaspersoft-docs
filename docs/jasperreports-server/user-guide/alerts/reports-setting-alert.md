# Setting Alert in the Report Viewer

From the Report Viewer, you can set up an alert in the report.

To set up an alert in the report

1.  Locate the report and run the selected report on which you want to set up an alert.

2.  Create the alert as described in [Creating an Alert](create-alert.md).

    !!! note

        Jive operations cannot be performed when alert mode is enabled.

For information about viewing, modifying, or deleting the alerts, see [Alerting in Reports](alerts-introduction.md).
