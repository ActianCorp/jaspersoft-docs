# Creating a Mondrian Connection

An OLAP client connection defines the type of connection and the source of the data. There are two types of OLAP client connections: Mondrian connections refer to local data sources in the repository; XML/A connections refer to data sources stored in a different repository or system. Only Mondrian connections can directly include an access grant definition. For more information on XML/A, refer to [XML/A Definitions](../administer/xml_a_definitions.md).

For a detailed description of this process, see the Jaspersoft OLAP User Guide, which is available from Jaspersoft's community website [http://community.jaspersoft.com](http://community.jaspersoft.com/).
