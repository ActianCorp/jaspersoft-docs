# Restoring Display of Small Columns/Bars

With migration of Highcharts version 10 to version 11, the property `plotOptions.series.minPointLength` defaults to zero, due to which small columns or bars are not displayed in the chart. To ensure that the columns or bars are visible, set the property to a value of 3 or more in the Ad Hoc designer, under advanced properties section.
