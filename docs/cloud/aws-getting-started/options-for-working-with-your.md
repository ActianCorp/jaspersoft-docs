# Options for Working with Your Data

Work with your data either of these ways:

- In a browser with JasperReports Server installed on AWS:

Once you set up this environment, your end-users can quickly and easily build simple visualizations and reports to interact with their data.

- Domains: metadata layer for abstracting logical terms from technical items. Non-technical users can use this “semantic layer” to drag and drop logical business items to build reports and interact with their data.

and / or

- - Topics: essentially pre-defined queries. that you can drag and drop in reports. Topics take less time to set up than Domains but provide less granular control of data.
- In the Jaspersoft Studio Professional client installed at your workstation. This environment is for technical users with knowledge of SQL to create sophisticated reports and deploy them to the JasperReports Server repository.
