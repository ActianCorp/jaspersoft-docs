# How Telemetry Data is Reported to Jaspersoft?

The telemetry program automatically gathers system and application usage data from your JasperReports Server instance. This information is then securely and electronically sent to Jaspersoft's internal systems.

-   Automatic Uploads: Data transmission occurs automatically from JasperReports Server instances that are connected to the internet.

-   Offline/Private Networks: If your JasperReports Server instance is on a private network or is offline, data will not be automatically captured or transmitted to Jaspersoft. This effectively serves as an opt-out for such environments.

-   Opting out of the Hotfix: Customers who do not wish to participate in the telemetry program can simply choose not to apply the latest hotfix to their JasperReports Server deployment. This prevents the telemetry program from being implemented in their environment.
