# Data Storage

The deployment of JasperReports Server is managed by the customer. They can choose to deploy it on-prem or on cloud or go with Hybrid deployment. Jaspersoft has no visibility and controls of customer deployment.

For cloud-hosted products, the data is hosted by cloud providers. Jaspersoft has marketplace offerings on AWS and Azure. The metadata and data is hosted on the cloud databases selected by the customer. The customer can opt for all regional instances, except China.
