# 1.1 The job Service

!!! note

    The rest/job service is superseded by [The v2/jobs Service](the_v2_jobs_service.md).

The job service lets you view details of a scheduled report (called a job), edit them, create new jobs, and delete existing ones. For interacting with existing jobs, use the jobID that you obtained from the jobsummary service.
