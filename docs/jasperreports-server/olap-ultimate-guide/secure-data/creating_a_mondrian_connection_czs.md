# Creating a Mondrian Connection

CZS created a Mondrian connection that included the czs-sales-grant.agxml access grant definition file. Ad Hoc views, reports, OLAP views, and XML/A connections that use this Mondrian connection impose the data level security rules defined in the AGXML file.

For detailed instructions on creating a Mondrian connection that includes an access grant, refer to the Jaspersoft OLAP User Guide.
