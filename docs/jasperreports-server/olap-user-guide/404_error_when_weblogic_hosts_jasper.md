# 404 Error When WebLogic Hosts Jaspersoft OLAP

!!! info "Important"

    This section describes functionality that can be restricted by the software license for JasperReports Server. If you do not see some of the options described in this section, your license may prohibit you from using them. To find out what you are licensed to use, or to upgrade your license, contact Jaspersoft.

If Jaspersoft OLAP is hosted by WebLogic, you may encounter 404 errors when changing the data cube in your OLAP views. To fix the issue, you must update your WebLogic configuration and delete files from your file system. For more information, refer to the JasperReports Server Installation Guide.
