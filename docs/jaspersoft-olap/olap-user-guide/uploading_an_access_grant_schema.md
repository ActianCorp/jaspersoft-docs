# Uploading an Access Grant Schema

To upload an access grant schema (AGXML)

1.  Click **View\> Repository** .

The repository page appears.

1.  In the **Folders** panel, navigate to **Organization \> Organization \> Analysis Components \> Analysis Schemas**.
2.  Right-click the folder and select **Add Resource \> File \> Access Grant Schema.**

The **Upload a File From Your Local Computer** page appears and prompts you to select a file and set its properties.

![ja add access grant definition agxml](assets/images/ja-add-access-grant-definition-agxml.png)

*Figure 1: Upload a File From Your Local Computer - Access Grant Schema*

1.  Under **Path to File**, click **Choose File** and locate the access grant schema you want to add.
2.  Enter a name and description for the schema.

The **Resource ID** is auto-generated as you type in the **Name** field. You can change the ID if necessary.

1.  To select a different folder to hold the schema, click **Browse** next to the **Save Location** field and navigate to the location in the repository where you want the file to reside.
2.  Click **Submit**.

The new file appears in the repository.
