# 1.1 System Requirements

Before getting started with version 2.0 of the Jaspersoft Mobile SDK for iOS, take a moment to confirm that your development computer meets the following system requirements.

| Supported Operating Systems                |
|--------------------------------------------|
| Mac OS X (10.10 or later, x86 64-bit only) |

As with all iOS libraries, the Jaspersoft Mobile SDK for iOS is supported only in Xcode:

| Supported IDE       |
|---------------------|
| Xcode v6.4 or later |
