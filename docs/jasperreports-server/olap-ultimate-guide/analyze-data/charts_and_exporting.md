# Charts and Exporting

When your view has the layout and data you need, you can use it to create a chart, or export it to a number of useful formats, such as PDF and Excel. For more information, see the Jaspersoft OLAP User Guide, available from Jaspersoft’s community website [http://community.jaspersoft.com](http://community.jaspersoft.com/).
