# Working with the Domain Designer

This chapter covers the process of creating a Domain and defining its contents through the Domain Designer. It covers the basic functionality on the various tabs of the user interface. For complex joins, derived tables, and calcuated fields, see [Advanced Domain Topics](../advanced_domains/advanced_domains_intro.md).

For instructions about creating views based on Domains in the Ad Hoc Editor, see the JasperReports Server User Guide. Domains defined in the server can be accessed through Jaspersoft Studio as well.

This chapter contains the following sections:

- [Opening the Domain Designer](using.md)
- [Overview of the Domain Designer](overview.md)
- [The Data Management Tab](data-management.md)
- [The Joins Tab](joins-tab.md)
- [The Pre-filters Tab](prefilters-tab.md)
- [The Data Presentation Tab](presentation-tab.md)
- [The Security Tab](security-tab.md)
- [The Locales Tab](locales-tab.md)
