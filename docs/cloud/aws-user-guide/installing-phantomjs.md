# Chrome AWS

JasperReports Server uses the Chrome JavaScript engine to generate graphical reports that are run in the background or scheduled and to export dashboards to PDF and other output formats.

JasperReports Server requires the installation of Google Chrome to enable the export functionality. If you wish to proceed with the installation of Chrome, review the [Google Terms of Service](https://www.google.com/intl/en_in/chrome/terms/) and [Google Chrome and ChromeOS Additional Terms of Service](https://policies.google.com/terms#toc-software), and select **Yes** from the dropdown to acknowledge the terms.

You can use Chrome, Chromium, or any other browser based on Chromium like Microsoft Edge.

For more information about Chrome/Chromium in JasperReports Server, see the JasperReports Server Administrator Guide.
